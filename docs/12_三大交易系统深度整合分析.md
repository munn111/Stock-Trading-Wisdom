# 三大交易系统 · 深度整合分析

> 不再各自为政。将 ashare-sop-engine、youzi-trading-skill、a-stock-1to2 的规则拧成一条可运转的决策链。
> 从交叉验证出发，到融合架构落地，最后给出 STW v4.0 可执行方案。
> 2026-08-08 · 仅供学习参考

## 第一章 · 为什么需要整合

三个项目各自都有完整的方法论，但分开使用时存在三个断层：

| 断层 | 问题 | 示例 |
|---|---|---|
| **断层一：环境判定口径不统一** | ashare-sop 用 MA20/MA60 + 涨跌比判定三类环境；youzi 用赚钱效应/成交量/热点持续度判定三类环境；两套标准怎么对齐？ | 同一个市场，ashare-sop 判"多头趋势"，youzi 判"震荡"，该听谁的？ |
| **断层二：选股信号分散** | ashare-sop 的 L3 buy_score 和 a-stock-1to2 的 11 维评分各自输出排名，两套排名打架时无从下手 | buy_score=4 的票在 11 维评分中只有 45 分，到底买不买？ |
| **断层三：战法与规则脱节** | youzi 的"龙头主升战法"是定性心法，ashare-sop 的 L3 是量化规则，两者之间缺少桥梁 | "只做龙头"四个字→对应 buy_score 的哪一条？ |

整合的目标：**三个系统拧成一根决策链条，每一步都有唯一的判定标准，信号不打架。**

## 第三章 · 交叉验证矩阵

三个系统在关键判断点上互相验证，分歧时取保守值。

### 3.1 L1 环境判定交叉验证

| 场景 | ashare-sop 判 | youzi 判 | 融合判定 | 仓位 | 说明 |
|---|---|---|---|---|---|
| 场景A | 多头趋势 | 强势 | **正常模式** | 60-80% | 双系统一致，全速运行 |
| 场景B | 震荡市 | 震荡 | **降低权重** | 30-50% | 一致偏中性 |
| 场景C | 系统性风险 | 弱势 | **全局屏蔽** | 0-20% | 双系统一致看空 |
| 场景D | 多头趋势 | 震荡 | **降低权重** | 30-50% | 分歧！取更保守（youzi 优先，因 youzi 更关注微观赚钱效应） |
| 场景E | 震荡市 | 强势 | **降低权重** | 30-50% | 分歧！取更保守（ashare-sop 因为均线趋势未确认） |

**融合规则**：L1 = 两套系统中更保守的那个。youzi 判弱市时，无论 ashare-sop 判什么，都不做。

### 3.2 L2 主线确认交叉验证

| 验证层 | 规则 | 通过=主线 |
|---|---|---|
| **ashare-sop L2** | 板块涨幅>3% + 涨停≥3 + 连板龙头 + 连续2天 | 入选活跃题材池 |
| **youzi 龙头三要素** | 板块内最大涨幅 + 最高人气 + 最强带动效应 | 真龙头确认 |
| **1to2 板块权重** | SECTOR_PREMIUM 板块热度评分 ≥ 6 | 高热度板块 |
| **融合结论** | 三项至少通过两项 + ashare-sop 四阶段非退潮期 | **主线锁定** |

### 3.3 L3 选股信号交叉验证

同一只股票，三套系统同时打分：

| 信号成分 | 评分来源 | 权重 | 意义 |
|---|---|---|---|
| buy_score 成分 | ashare-sop L3（9条量化规则） | **30%** | 技术面量化信号，全市场回测验证 |
| 11维评分 | a-stock-1to2（100分制） | **40%** | 1进2专项评分，维度最全面 |
| 战法匹配 | youzi（三大战法条件） | **30%** | 与游资心法的一致性 |

综合评分 = buy_score/5 × 100 × 30% + 11维得分 × 40% + 战法匹配系数 × 100 × 30%

**输出规则**：
- 综合评分 ≥ 60 → **强烈候选**（三系统共振）
- 综合评分 45-59 → **一般候选**（两系统共振）
- 综合评分 < 45 → **不输出**（仅单一系统信号，不可靠）

## 第四章 · 实战场景演练

### 4.1 场景一：强势市场环境下的选股

**盘前数据**：
- 上证 MA20=3400(↑) MA60=3200(↑)，全市场成交 28000亿
- 涨跌比 3:1，涨停 102只，炸板率 18%
- ashare-sop 判：**多头趋势** ✓
- youzi 判：**强势**（龙头连续涨停+持续热点+情绪高涨）✓
- 融合 L1：**正常模式，仓位上限 80%**

**日间扫描**：
- 有色金属板块涨幅 4.2%，涨停 8只，其中云南锗业 3连板
- ashare-sop L2 入选 ✓（连续2天满足）
- youzi 龙头确认 ✓（板块最大涨幅+最高人气+带动效应）
- 1to2 SECTOR_PREMIUM 有色=8 ≥ 6 ✓
- 融合 L2：**有色金属 — 主线锁定，高潮/主升期**

**个股评分（以云南锗业为例）**：
- buy_score：R2(重上5日线+放量)✓ + R3(5/10线上方走强)✓ + R5(刷新20D高点)✓ → score=3
- 11维评分：市值48亿(13/15) + 换手5.8%(14/15) + 量比2.3x(10/12) + 封板<2%(10/12) + 股价略高(5/8) + 板块强度18/18 + 龙虎榜机构买入(14/15) + DDE 3.2(8/8) + 主板(5/5) + PE合理(3/4) → **总分 100/100**
- 战法匹配：龙头主升战法（4/4步骤全满足）✓ + 打板战法（4/4条件全满足）✓ → 战法匹配系数 1.0
- 综合评分 = 3/5×100×0.3 + 100×0.4 + 1.0×100×0.3 = 18+40+30 = **88** → **强烈候选** ✅

**L4 执行**：
- 仓位上限 = min(80%/环境, 20%/1to2单票) × 综合评分强度系数 = 20%
- 止损：亏损 3% 无条件止损（1to2 硬止损）或 次日不涨停离场（youzi + 1to2）
- 人工确认：三个系统五条风控规则全部绿灯 → 执行

### 4.2 场景二：退潮期风控触发

**盘前数据**：
- 上证 MA20=3350(↓) MA60=3290(↑)，MA20 下穿 MA60 但未跌破
- 全市场成交 18000亿（较前日缩量 30%）
- 涨跌比 0.3:1，涨停 28只，炸板率 45%
- 龙头大面积断板，昨日三只 6连板股全部跌停开盘
- ashare-sop 判：**震荡市**（MA20/MA60 方向背离）
- youzi 判：**弱势**（龙头都在跌+缩量+热点无持续+涨停少）
- 融合 L1：**全局屏蔽**（youzi 判弱市，取更保守 → 不做）

**规则触发链**：
1. youzi 硬规则 #3「弱市不做」触发 → 所有买入建议暂停
2. youzi 仓位映射 → 0-20%，建议空仓
3. ashare-sop L2 如判退潮期 → 全局清空所有候选
4. 三个系统一致 → 输出「建议空仓，等待环境改善」

**即使有票触发 buy_score=4 也 不输出。这就是融合 L1 闸门的价值。**

### 4.3 场景三：两系统分歧时的处理

**情况**：ashare-sop L1 判震荡市，youzi 判强势

**分析**：
- ashare-sop 判震荡市的可能原因：指数在 MA20/MA60 之间反复，均线方向不明确
- youzi 判强势的可能原因：局部热点持续、涨停数多、赚钱效应局部集中
- 这是典型的"指数震荡、题材活跃"行情

**融合判定**：按本文 L1 融合规则，分歧时取更保守方 → **降低权重，仓位上限 50%**
- L2/L3 继续运行但需要更强的信号共振
- 综合评分阈值从 45 提高至 55
- 在降低权重下，如果 buy_score=4 或 11维≥80 → 仍可输出候选观察
- 核心逻辑：震荡市找"熊市中的牛股"，不降低仓位上限，但提高选股标准

## 第八章 · 融合实战速查卡

### 每日开盘前（08:30）

```
1. 运行 L1 融合判定
   → 取 ashare-sop MA20/MA60 方向 + youzi 赚钱效应/热点持续度/涨停炸板率
   → 双系统一致 → 输出环境状态 + 仓位上限
   → 分歧 → 取更保守方 + 打印分歧原因

2. 输出：今天能不能做，能做多少仓位
```

### 盘间（09:30-15:00）

```
3. 每分钟扫描 L2 题材
   → 涨幅>3%+涨停≥3+连板 → 自动入池
   → 连续2天 → 标记为观察池
   → 计算四阶段生命周期 + 量化健康度

4. 每分钟扫描 L3 个股
   → buy_score ≥ 2 且 ≥ sell_score+1 → 进入初筛
   → 叠加 11 维评分 + 战法匹配 → 综合评分
   → 综合≥60 → 强烈候选；45-59 → 一般候选；<45 → 不输出
   → 同股 20 分钟不重复报警
```

### 收盘后（15:00-16:00）

```
5. L4 执行复盘
   → 当日信号回收：哪些触发、哪些执行、哪些错过
   → 样本录入：buy_score + 11维 + 战法匹配 + 实际结果
   → 周度汇总：胜率/盈亏比/错误分类
```
