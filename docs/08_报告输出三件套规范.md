## 一、三件套定义

| 产物 | 扩展名 | 定位 | 必须包含 |
|---|---|---|---|
| **MD文件** | `.md` | 单一真相源，结构化文本 | 标题层级 + 数据表格 + 逻辑推导 + 结论 |
| **HTML文件** | `.html` | 深色科技风单文件，浏览器预览 | 同MD内容 + 视觉卡片 + 涨红跌绿 |
| **PPT文件** | `.pptx` | 16:9 演示版，同款深色主题 | 同MD内容，每页一主题，python-pptx生成 |

**铁律：三件缺一不可。出报告必须 MD + HTML + PPT 一起给。**

### 基础模板代码
```python
from pptx import Presentation
from pptx.util import Inches, Pt, Emu
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN

# 配色常量
BG_DARK   = RGBColor(0x07, 0x0b, 0x16)
RED_UP    = RGBColor(0xff, 0x5a, 0x5f)
GREEN_DN  = RGBColor(0x1e, 0xd7, 0x60)
CYAN      = RGBColor(0x00, 0xd4, 0xff)
WHITE     = RGBColor(0xe0, 0xe6, 0xf0)
GRAY      = RGBColor(0x88, 0x92, 0xb0)

prs = Presentation()
prs.slide_width  = Inches(13.333)  # 16:9
prs.slide_height = Inches(7.5)

def add_bg(slide):
    """铺满深色背景"""
    bg = slide.background
    fill = bg.fill
    fill.solid()
    fill.fore_color.rgb = BG_DARK

def add_title(slide, text, left, top, width, height, size=28, color=CYAN):
    """添加标题文本框"""
    txBox = slide.shapes.add_textbox(Inches(left), Inches(top), Inches(width), Inches(height))
    tf = txBox.text_frame
    tf.word_wrap = True
    p = tf.paragraphs[0]
    p.text = text
    p.font.size = Pt(size)
    p.font.color.rgb = color
    p.font.bold = True
    return tf

def add_table(slide, headers, rows, left, top, width, height, col_widths):
    """添加表格 (列宽必须是整数Inches)"""
    table_shape = slide.shapes.add_table(len(rows)+1, len(headers), 
                                          Inches(left), Inches(top), 
                                          Inches(width), Inches(height))
    table = table_shape.table
    # 设置列宽 (必须是整数EMU)
    for i, w in enumerate(col_widths):
        table.columns[i].width = Inches(int(w))
    # 填表头
    for i, h in enumerate(headers):
        cell = table.cell(0, i)
        cell.text = h
        cell.fill.solid()
        cell.fill.fore_color.rgb = RGBColor(0x1a, 0x22, 0x40)
        for p in cell.text_frame.paragraphs:
            p.font.size = Pt(10)
            p.font.color.rgb = CYAN
            p.font.bold = True
    # 填数据
    for r, row in enumerate(rows):
        for c, val in enumerate(row):
            cell = table.cell(r+1, c)
            cell.text = str(val)
            for p in cell.text_frame.paragraphs:
                p.font.size = Pt(10)
                p.font.color.rgb = WHITE
    return table

# 示例：创建封面
slide = prs.slides.add_slide(prs.slide_layouts[6])  # blank
add_bg(slide)
add_title(slide, "报告标题", 1, 2.5, 11, 2, 40, CYAN)
add_title(slide, "2026-XX-XX | 数据源标注", 1, 4.5, 11, 1, 18, GRAY)

prs.save("output.pptx")
```

### 常见陷阱
| 陷阱 | 现象 | 解决 |
|---|---|---|
| 列宽浮点 | `TypeError: value must be an integral type` | 用 `Inches(int(x))` 而非 `Inches(x*0.3)` |
| 中文引号 | 在f-string中语法错误 | 改用Unicode转义或独立字符串 |
| 字符串编码 | `墨` → `寿` 损坏 | 用字节替换修复 |
| 批量渲染慢 | 表格多时生成>30s | 减少表格页，关键数据用图表 |
