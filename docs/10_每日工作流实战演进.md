## 二、午盘：验证与调整 (11:30-12:00)

### 数据获取流程
```
1. 五大指数行情
   → westock-data quote (或 tdx-connector tdx_quotes 单只并行)
   → 注意：午盘窗口(11:30左右) quote 可能报 SKILL_004，改用 tdx

2. 板块涨跌榜
   → westock-data sector ranking (涨榜) + SW1行业手动 quote (跌榜)

3. 涨跌分布
   → westock-data changedist (上涨/下跌/平盘比例)

4. 涨停/连板梯队
   → tdx-connector tdx_screener (涨停/连板/10天内涨停)

5. 市场画像
   → westock-data market-overview --type all

6. 资金流向
   → sector ranking 的 mainNetInflow (注意字符串转float)
```

### 午盘判断维度
| 维度 | 关键指标 | 判断依据 |
|---|---|---|
| 指数环境 | 五大指数涨跌+成交量 | 放量进攻 vs 缩量震荡 vs 放量下跌 |
| 板块强度 | 涨幅/涨停家数/成交额/龙头封单 | 有主线 vs 无主线 vs 多线纷杂 |
| 连板情绪 | 连板高度/断板率/封板率 | 高潮 vs 退潮 vs 冰点 |
| 风格轮动 | 大小盘/价值成长/行业轮动 | 极端分化 vs 均衡轮动 |
| 资金方向 | 主力净流入/流出行业 | 进攻 vs 防御 |

## 三、收盘：涨停复盘 (15:00-17:00)

### 数据获取
```
1. 涨停全量 + 封单信息
   → tdx-connector tdx_screener (涨停/首板/连板)

2. 龙虎榜
   → westock-data lhb (盘后才有数据)

3. 涨停归因
   → 手动分析：事件催化 + 题材关联 + 梯队角色

4. 与昨日预判对照
   → 哪些命中？哪些打脸？为什么？
```

### 复盘输出结构
```
1. 市场全景：指数涨跌 + 成交额 + 涨跌比 + 涨跌停数
2. 主线分类：每条主线(涨停家数/龙头/中军/事件催化)
3. 连板梯队：高度龙 → 四板 → 三板 → 二板 → 首板
4. 封单TOP：封单金额/封成比排名
5. 龙虎榜：知名游资动向 + 机构买入
6. 与午盘对比：哪些延续？哪些反转？
7. 操作建议 + 风控
```

## 五、风控底线 (不变)

1. 不把未经验证的网络传闻当作交易依据
2. 不把板块利好自动等同于个股利好
3. 不在全市场数据源异常时强行输出"确定结论"
4. 不因为某只股票符合形态就忽略指数环境和板块退潮
5. 所有报告仅供学习交流，不构成投资建议
6. 盘中快照不固化判断，盘后必须复核收盘数据再下结论
