## 写在前面

交易这件事，拆到底只有两个问题：**认识交易**（市场是什么），**认识自己**（我是谁、我会犯什么错）。

大部分散户死在第二个上——不是不懂技术，而是懂了技术也管不住手。所以这份心得的结构是：先用市场微观结构把"战场"看清楚，再用板块生命周期把"标的"分清楚，然后用情绪叙事把"节奏"踩准，最后用人性工程化和纪律闭环把"自己"管住。

**一句话总结全文**：市场是四种人的博弈场，标的有生命周期，情绪有神明周期，而你需要一套否决权体系来阻止自己犯蠢。

## 第一章 · 市场本质 — 零和博弈与四种人

### 1.1 地基：钱从a口袋到b口袋

股市不创造生产资料。你赚的每一分钱，都是别人亏的。这个认知是后面所有框架的底层假设——没有它，"主力""预期""神明"全是空谈。

因为是对手盘博弈，所以**默认状态是跌**。涨需要合力（资金+情绪+预期一致），跌只需要合力瓦解（任何一方砸盘就行）。这就是为什么A股权重股熊市能阴跌三年——不需要做空，只要多头不干活，自由落体就够了。

### 1.2 四种人六种情况：A股最硬的微观结构

一只股票里永远有四种人：

| 参与者 | 持仓状态 | 行为倾向 | 砸盘概率 |
|--------|---------|---------|---------|
| **获利盘** | 低位买入，成本极低 | 随时可以一键砸盘 | 高 |
| **套牢盘** | 高位买入被套 | 随时可能割肉砸盘 | 高 |
| **量化空头** | 当天融券卖出 | 第二天必然砸盘获利 | 极高 |
| **多头韭菜** | 当天买入 | 情况不对随时翻空 | 中 |

四种人分化出**6种情况**：4种砸盘 vs 2种加仓。

**这个2:4的天然偏空结构是整篇文章最有工程价值的结论。** 它意味着：

- 你买入的那一刻，场内有4股力量随时可能砸你
- 只有"预期从分歧转一致"时，砸盘力量才会暂时收敛
- 昨天涨停的票，今天必然分歧——因为昨天的多头今天大部分想跑

### 1.3 预期：分歧与一致的钟摆

预期的本质只有两种状态：**分歧**和**一致**。

```
分歧 → 一致：加仓力量占上风，空头变多头，股价上升
一致 → 分歧：昨天红的今天必分歧，多头变空头，股价承压
```

**关键洞察**："人是刹那芳华的生物，赚钱了就跑才是主流。" 这句话解释了为什么A股的连板断层率极高——每个涨停板都是一次分歧测试，扛住了继续走，扛不住就是炸板。

日内预判的实操规则：

| 第二天竞价形态 | 含义 | 建议 |
|---------------|------|------|
| 平开但开在5日线下 | 完蛋，开盘跌继续跌 | 观望或减仓 |
| 大低开 | 散户舍不得卖，反而好事 | 可能横盘吸筹，不急卖 |
| 高开+急拉2个点 | 大概率诱多 | 先卖再说 |
| 高开+涨2个点还在拉 | 超预期 | 可以追一下 |

### 1.4 场内票与场外资金：弹性和增量

**场内票是恒定的**——每一次卖出都是真实的货在卖。急跌后缩量 = 卖盘没货了 = 1天反弹。但反弹≠反转，**5日线上穿20日线才是趋势反转信号**。

**场外资金看情绪周期**：
- 高标断板 → 大资金出来 → 可能进你的票（增量来了）
- 高标继续拉 → 资金被吸走 → 你的票阴跌（存量博弈）
- 大盘不好 → 主力不干活 → 散户杀散户 → 阴跌无底线

## 第二章 · 板块生命周期 — 从"科技吹"到"蓝筹王"

### 2.1 四个版本的本质区别

A股的每只股票都有"版本号"，对应不同的业绩阶段和玩法：

| 版本 | 业绩 | 故事 | 市值 | 核心玩法 | 散户心态 |
|------|------|------|------|----------|----------|
| **科技股** | 无/亏损 | 极大（颠覆叙事） | 50-300亿 | 追概念、博弈预期 | "这次不一样" |
| **题材股** | 无 | 中等（讲题材） | 30-150亿 | 跟庄、博傻、看龙虎榜 | "跟对大哥吃肉" |
| **成长股** | 有（增速20%+） | 小（业绩说话） | 100-1000亿 | 估值切换、跟机构 | "等业绩兑现" |
| **周期蓝筹** | 有（5-15%） | 0 | 1000亿+ | 吃股息、扛波动 | "养老仓" |

### 2.2 版本升级的残酷概率

```
上市 (IPO)
  ↓
科技股（99%死在量产前夜）
  ↓ 股东减持 / 故事破灭
题材股（纯资金游戏，退潮一地鸡毛）
  ↓ 少数股东不卖，搞出业绩
成长股（业绩兑现，市值爬坡）
  ↓ 运气好 + 时代红利
周期蓝筹（千亿市值，稳定分红）
```

**10年能从科技股走到蓝筹的不超过20家**（宁德、迈瑞、药明等）。绝大多数公司一辈子卡在"科技股"或"题材股"阶段。

### 2.3 各版本的实战定位

**科技股 = 流量担当**：贡献两市成交30%+，是散户情绪指标。买的是"未来5年故事"，必须在故事最动听时离场。

**题材股 = 赌场**：提供投机场所，给游资活路。本质是"看图说话+跟庄"，**只做龙头不做杂毛**——龙头多条命，杂毛一字断魂刀。

**成长股 = 中坚力量**：机构主战场，公募基金重仓。核心是**业绩验证窗口期**——每次季报前后20天是"生死劫"，超预期=主升浪，不及预期=戴维斯双杀。

**周期蓝筹 = 压舱石**：指数权重，社保养老金主战场。股息率5%是入场信号，市净率破净是送钱机会。但要耐得住2-3年不涨。

### 2.4 大盘风格决定打法

| 大盘状态 | 机构行为 | 游资行为 | 你的打法 |
|---------|---------|---------|---------|
| **岁月静好（向上）** | 做趋势大票（科技大票逻辑） | 被压制 | 跟机构做趋势大票 |
| **风雨飘摇（向下）** | 去红利股避险 | 出来造龙 | 做连板，最高标打开高度 |

**核心规律**：连板行情只在大盘差的时候出现。大盘好的时候做机构趋势票，大盘差的时候做游资连板票——这是风格切换的根本逻辑。

## 第三章 · 情绪叙事 — 虚空神明与季节周期

### 3.1 神明理论：国运→消息→人心→资金→热点

这是把情绪周期上升到国运级别的原创框架。

**神 = 国运分身**，由消息和人心构成。100个手握上亿资金的人集体看好一个方向，这个方向就出"神明"。

神有三身：
- **过去身**：已退场的热点（别恋战）
- **现在身**：正在走的主线（跟不跟看位置）
- **未来身**：将起未起的暗线（提前一个半月埋伏）

### 3.2 神的七条基本规则

1. **利国利民** — 不利国的方向出不了大神
2. **情绪多为自豪与兴奋** — 偶尔猎奇与肯定
3. **新神比老神有魅力** — 昨天的热点今天没人看
4. **资金自动跟随神** — 不需要号召，大资金自己会判断
5. **神容易在出现后不断加强** — 正反馈循环
6. **神只在将发生未发生时出现** — 落地即退场
7. **神必然跟随节点出现** — 不可能大夏天炒过年票

### 3.3 大神 vs 小神

| 维度 | 大神 | 小神 |
|------|------|------|
| 情绪 | 民族自豪感 | 大神的具体化 |
| 覆盖 | 全民参与 | 地图/寓意/小众 |
| 指标 | 微信指数狂飙 | 无容量大票 |
| 罕见性 | 多年一遇 | 常见 |
| 高度 | 6板以上带头 | 普遍三板到头 |

**小神是大神的子神**——比如"水产"是"抗日"的子神，大方向已被大神占了，子方向大概率一日游。

### 3.4 季节性选股日历

| 月份 | 方向 | 逻辑 |
|------|------|------|
| 1月 | 三农 | 中央一号文件 |
| 2-3月 | 两会 | 政策预期 |
| 4月 | 年报 | 业绩驱动 |

| 8-9月 | 科技 | 秋季新品发布季 |
| 深秋 | 喝酒吃药 | 消费旺季 |
| 初冬 | 寓意 | "中华必胜""万里长城"等讨资金喜欢 |
| 夏天 | 电力 | 用电高峰 |
| 冬天 | 煤炭 | 供暖需求 |

### 3.5 三连爆入场标准

**节点选择的可操作标准**（三个信号同时出现=入场）：

1. **人民日报连发三天** — 官媒定调（如台湾、稀土）
2. **抖音连续三天爆火** — 大众情绪点燃（如苏超）
3. **微信指数爆棚** — 全民关注（如731电影，8月3日热度九千万，次日吉视传媒开启主升浪）

**重大活动提前一个半月入场**（如全运会、大阅兵）。

## 第四章 · 人性工程化 — 七种心理与四层否决

### 4.1 核心原则：不是消灭情绪，是给情绪找出口

散户的七大经典心理陷阱，每一种都有对应的工程化解决方案：

| 心理陷阱 | 本质 | 工程化出口 |
|---------|------|-----------|
| **恐高不敢买** | 怕亏，但看着涨难受 | 轻仓先上车，满足情绪 |
| **利好追入** | 涨完了才出利好=出货信号 | 反着做，赶紧走 |
| **一买就套不割** | 厌恶损失心理 | 高位无脑减一半 |
| **幻想会回来** | 不肯认错 | 看板块！同周期都在跌=放弃幻想 |
| **越加越跌** | 沉没成本谬误 | 等到前一个横盘最久的位置才加 |
| **反弹不卖** | 想回本再卖 | 反弹先卖加仓部分=回血+降风险 |
| **继续跌还补** | 赌徒心理 | 跌破中枢必须等下个中枢，看买盘不看卖盘 |

**这七条的底层逻辑**：不试图消灭人性（做不到），而是把心理冲动转化为可执行动作。恐高了→轻仓上车；套住了→减一半；想加仓了→等横盘位。

### 4.2 四层否决权体系（来自FeishuClaw v4.0）

在七种心理之上，叠加一套分层否决权——每层都有权否决下面的所有决策：

```
L0 人性层（最高否决权）
  ↓ 住相信号 ≥3 → 减仓 / ≥4 → 清仓，一切归零
L1 情绪层
  ↓ STW情绪周期判定：冰点/复苏/高潮/退潮
L2 产业层
  ↓ Serenity供应链卡位：瓶颈→替代→国产化→订单
L3 证据层
  ↓ Chokepoint Atlas：证据阶梯 A/B/C/D + 五维评分
```

**L0是最高否决权**——不管L1/L2/L3多么看好，只要L0的住相信号链触发（五维破裂检测≥3），直接减仓/清仓。

### 4.3 住相信号链：五维破裂检测

五维信号对应"住相"——即对某只股票产生了执念。当执念的支撑维度开始破裂时，就是减仓信号：

| 维度 | 正常状态 | 破裂信号 |
|------|---------|---------|
| **趋势** | 5日线上穿20日线 | 5日线下穿20日线 |
| **量能** | 放量上涨 | 缩量上涨/放量下跌 |
| **板块** | 同板块齐涨 | 板块分化，龙头独走 |
| **位置** | 中低位 | 高位滞涨 |
| **预期** | 预期一致 | 预期分歧，多头变空头 |

- **3维破裂 → 减仓一半**（绕开厌恶损失心理）
- **4维破裂 → 清仓**（不要幻想）
- **5维破裂 → 已经晚了，割肉也要走**

### 4.4 执念六阶段

配合住相信号链，执念本身也有生命周期：

```
确认 → 发酵 → 分歧 → 高潮 → 衰退 → 退潮
```

- **确认-发酵期**：安全区间，可以加仓
- **分歧期**：第一次大考，看能不能扛住
- **高潮期**：最危险，看起来最好但随时可能退潮
- **衰退-退潮期**：坚决离场，不要恋战

## 第五章 · 交易纪律闭环 — 从认知到执行

### 5.1 完整决策链

把前面四章串成一条可执行的决策链：

```
① 市场本质判定（零和博弈，默认偏空）
     ↓
② 大盘风格判定（好→趋势大票 / 差→连板龙头）
     ↓
③ 板块生命周期定位（科技/题材/成长/蓝筹 → 定玩法）
     ↓
④ 情绪叙事判定（神明三身 + 季节周期 + 三连爆）
     ↓
⑤ L0人性否决权检查（住相信号链 ≥3减仓 / ≥4清仓）
     ↓
⑥ L1情绪周期确认（冰点试错 / 高潮打板 / 退潮离场）
     ↓
⑦ L2产业层验证（供应链卡位 + 国产化率 + 订单兑现）
     ↓
⑧ L3证据层评分（证据阶梯 ≥B级才动手）
     ↓
⑨ 仓位管理（3331法则：30%底仓/30%加仓/30%机动/10%应急）
     ↓
⑩ 执行 + 止损纪律
```

**任何一步被否决，直接跳到止损/观望。** 这就是"否决权"的含义——不是建议，是硬规则。

### 5.2 买入前的十问检查清单

每次买入前，过一遍这十个问题。任何一题答"否"，就不要买：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 大盘风格适合这种打法吗？ | 好→趋势票 / 差→连板 |
| 2 | 这只票是哪个版本？ | 知道是科技/题材/成长/蓝筹 |
| 3 | 有"神明"加持吗？ | 有现在身或未来身 |
| 4 | 季节周期对吗？ | 符合季节性选股日历 |
| 5 | 三连爆信号出现了吗？ | 至少2个（官媒+抖音/微信指数） |
| 6 | L0住相信号链有几维破裂？ | ≤2维才可买 |
| 7 | 情绪周期在哪个阶段？ | 冰点/复苏可买，高潮谨慎，退潮不买 |
| 8 | 产业层有卡脖子逻辑吗？ | 供应链瓶颈+国产化率<50%优先 |
| 9 | 证据阶梯达到B级了吗？ | 有至少2个独立信息源支撑 |
| 10 | 仓位符合3331法则吗？ | 不超过单票30%总仓位 |

### 5.3 持仓中的七条纪律

持仓期间，每天检查：

1. **昨红今必分歧** — 昨天涨停的票，今天必然面临分歧测试，做好应对预案
2. **看板块不看个股** — 同周期板块都在跌，放弃幻想，开盘固定卖一半
3. **反弹先卖加仓部分** — 不等回本，回血+降风险
4. **加仓等横盘位** — 不是跌了就加，等前一个横盘最久的位置
5. **跌破中枢等下个中枢** — 不看卖盘看买盘，买盘放大才是真中枢
6. **获利盘比例监控** — 长期低于20%突然拉到20%以上=异动信号
7. **5日线与20日线关系** — 5日线下穿20日线=趋势反转确认，必须减仓

### 5.4 止损的铁律

| 触发条件 | 动作 | 心理应对 |
|---------|------|---------|
| 住相信号链≥3维破裂 | 减仓一半 | "我不是在认亏，是在执行规则" |
| 住相信号链≥4维破裂 | 清仓 | "规则大于幻想" |
| 跌破中枢且无买盘放大 | 割肉 | "等下个中枢再战" |
| 板块同周期全跌 | 每天开盘卖一半 | "看板块不看个股" |
| 高位利好消息 | 立即减仓 | "涨完出利好=出货信号" |

## 第六章 · 五层联动 — 综合实战框架

### 6.1 三角互补关系

经过综合，三套方法论形成三角互补：

```
        认识交易认识自己
       （市场博弈 + 人性工程）
            /        \
           /          \
    FeishuClaw        STW
  （管自己的纪律）  （管选股的量化）
```

| 方法论 | 核心职责 | 强项 | 弱项 |
|--------|---------|------|------|
| **认识交易认识自己** | 市场微观结构+情绪叙事 | 四种人六种情况、神明理论 | 缺量化标准 |
| **FeishuClaw四层否决权** | 人性纪律+分层否决 | 住相信号链、执念六阶段 | 缺可执行代码 |
| **STW七战法** | 选股量化+策略引擎 | 涨停/缺口/龙头/卡脖子/六维 | 缺人性否决层 |

**三角缺一不可**：
- 没有市场博弈认知 → 选股靠蒙
- 没有人性纪律 → 买了管不住手
- 没有量化战法 → 知道方向但不知道怎么选

### 6.2 日内作战流程


### 6.3 选股的"神明+战法"双引擎

选股不是单独靠技术面或单独靠消息面，而是**神明叙事 × 量化战法**的交集：

| 步骤 | 动作 | 工具 |
|------|------|------|
| 1 | 识别当前"神明"（现在身/未来身） | 季节日历 + 三连爆信号 |
| 2 | 在神明方向内选标的 | STW六维选股（政策/景气/ROE/PEG/技术/安全边际） |
| 3 | 确认板块生命周期版本 | 科技→题材→成长→蓝筹，定玩法 |
| 4 | 技术面确认入场点 | STW涨停回马枪 / 缺口理论 / 龙头战法 |
| 5 | L0否决权检查 | 住相信号链≤2维破裂 |
| 6 | 仓位分配 | 3331法则 |

**只做神明方向内的票**——不在神明覆盖范围内的票，技术面再好也不碰。这是"资金跟随神"规律的逆向应用。

## 第七章 · 常见误区与自我审计

### 7.1 七个致命误区

| 误区 | 真相 | 纠正 |
|------|------|------|
| "这次不一样" | 每次都一样，人性不变 | 看历史K线，找相似形态 |
| "利好=买入信号" | 涨完才出利好=出货信号 | 反着做 |
| "跌了就加仓摊薄成本" | 越加越跌=沉没成本陷阱 | 等横盘位才加 |
| "会回来的" | 同板块都在跌=不会回来 | 看板块不看个股 |
| "反弹再等等就回本了" | 反弹是减仓机会不是回本机会 | 先卖加仓部分 |
| "高位放量是好事" | 高位放量=散户接盘 | 赶紧走 |
| "我能抄底" | 底是走出来的不是猜出来的 | 等5日线上穿20日线 |

### 7.2 每周自我审计清单

每周收盘后，用这五个问题审计自己：

1. **这周我有没有在非神明方向买票？** — 如果有，说明你在赌不是在交易
2. **这周我的住相信号链有没有触发过≥3？** — 如果有，我执行了吗？
3. **这周我有没有"恐高不敢买"结果它一直涨？** — 如果有，下次轻仓上车
4. **这周我有没有"一买就套不割"？** — 如果有，高位减一半的规则没执行
5. **这周我的仓位符合3331法则吗？** — 如果单票超过30%，说明风控失效
