# 三系统融合决策方法论 v1.0

> 基于 ashare-sop-engine、youzi-trading-skill、a-stock-1to2 三大开源系统的规则提炼与有机融合。
> 四个步骤，覆盖从"能不能做"到"怎么复盘"的全链路。
> 每一步都有唯一的判定标准，每一条推荐都可追溯评分来源。

---

## 一、核心理念

### 1.1 四个铁律

| # | 铁律 | 含义 |
|---|---|---|
| 一 | **先判环境，再选方向** | 环境不允许时，任何选股信号都不输出。L1 是最大的 Alpha 来源（回测验证：加入 L1 过滤后 D5 超额收益 ×26.5 倍）。 |
| 二 | **买点重确认，卖点重纪律** | 用三层加权评分确认买入信号（量化 + 维度 + 战法），用统一风控执行卖出（三个系统取最严格值）。 |
| 三 | **分歧取保守，共振可加仓** | 当两套环境判定系统分歧时，取更保守的一方。当三套评分系统共振时（综合评分 ≥ 60），才有资格作为强烈候选。 |
| 四 | **人工终裁不可跳过** | 系统只输出"候选观察"，不自动下单。所有真实交易必须人工确认。引擎是辅助，决策权在人。 |

### 1.2 决策链条

```
L1 环境判定 → L2 主线锁定 → L3 标的评分 → L4 执行风控
 (能不能做)    (做什么方向)    (买哪一只)     (怎么买/怎么卖)
```

每一层都是下一层的闸门：L1 不开，L2 不启动；L2 无主线，L3 不选股；L3 不达标，L4 不执行。

## 二、第一步 · L1 环境判定

### 2.1 双系统交叉验证

同时运行两套环境判定系统，对比后做融合判定：

**系统 A：ashare-sop L1（均线趋势）**

| 环境状态 | 判定条件 |
|---|---|
| 多头趋势 | 上证/深证/创业板均收于 MA20 和 MA60 上方，双均线方向向上 |
| 震荡市 | 指数介于 MA20 与 MA60 之间；或 MA20/MA60 方向背离 |
| 系统性风险 | 任一指数日内跌 > 3%；或连续 3 日收于 MA20 以下且 MA20 向下；或情绪进入恐慌期 |

**系统 B：youzi 市场判断（赚钱效应）**

| 环境状态 | 判定条件 |
|---|---|
| 强势 | 龙头连续涨停 + 成交量放大 + 热点持续 > 3 天 + 涨停多 / 炸板少 |
| 震荡 | 涨跌互现 + 热点轮动快 + 成交量不稳定 |
| 弱势 | 龙头都在跌 + 成交量萎缩 + 热点稀缺 + 涨停少 / 炸板多 |

### 2.2 融合判定规则

| 系统 A | 系统 B | 融合结果 | 仓位上限 | L2/L3 权限 |
|---|---|---|---|---|
| 多头趋势 | 强势 | **正常模式** | 60-80% | 全速运行 |
| 震荡市 | 震荡 | **降低权重** | 30-50% | 需更强共振 |
| 系统性风险 | 弱势 | **全局屏蔽** | 0-20% | 禁止所有信号 |
| 多头趋势 | 震荡 | **降低权重** | 30-50% | 分歧，取更保守 |
| 震荡市 | 强势 | **降低权重** | 30-50% | 分歧，取更保守 |

> **铁律**：系统 B（youzi）判"弱势"时，无论系统 A 判什么，都执行全局屏蔽。弱市不做是硬规则。

### 2.3 L1 输出格式

```
L1 环境判定
├─ 系统A: [多头趋势/震荡市/系统性风险]
├─ 系统B: [强势/震荡/弱势]
├─ 融合结果: [正常模式/降低权重/全局屏蔽]
├─ 仓位上限: [60-80%/30-50%/0-20%]
└─ 分歧标记: [是/否] + 分歧原因
```

## 三、第二步 · L2 主线锁定

### 3.1 三验证体系

对每个候选板块，同时运行三层验证，至少通过两层 + 非退潮期 → 主线锁定。

| 验证层 | 来源 | 规则 | 通过标准 |
|---|---|---|---|
| **动态识别** | ashare-sop L2 | 板块涨幅 > 3% + 涨停 ≥ 3 只 + 有连板龙头（≥ 2 板）+ 连续 2 天满足 | 入选观察池 |
| **龙头确认** | youzi 龙头三要素 | 板块内最大涨幅 + 最高人气 + 最强带动效应 | 真龙头确认 |
| **热度评分** | 1to2 板块权重 | SECTOR_PREMIUM ≥ 6（可动态调整） | 高热度标记 |

### 3.2 四阶段生命周期

| 阶段 | 触发条件 | 操作 |
|---|---|---|
| **启动/发酵** | 新主题满足识别规则，是市场唯一强势方向 | 观察窗口，中期布局 |
| **高潮/主升** | 放量涨 3 天 +、核心龙头 4 板 +、大面积跟风涨停 | 持股待涨，警惕分歧 |
| **分歧/分化** | 涨幅收窄但量仍大、龙头放量分歧、后排掉队 | 去弱留强，风险最高 |
| **退潮** | 龙头断板无法回封、多股跌停、亏钱效应扩散 | 清仓离场 |

### 3.3 L2 输出格式

```
L2 题材扫描
├─ 主线: [板块名称] · 阶段: [四阶段之一] · 健康度: [四个指标评分]
├─ 龙头: [龙头股列表 + 连板数 + 带动效应]
├─ 观察池: [候选板块列表]
└─ 退潮池: [已退出板块列表]
```

## 四、第三步 · L3 标的评分

### 4.1 三层加权评分公式

```
综合评分 = ( buy_score / 5 × 100 ) × 30% + 11维得分 × 40% + 战法匹配系数 × 100 × 30%
```

### 4.2 第一层：buy_score（来源：ashare-sop L3）

| # | 规则 | 条件 | +分 |
|---|---|---|---|
| R2 | 重上 5 日线 + 放量 | 现价 > MA5 且 昨收 < 昨 MA5 且 换手 ≥ 5 日均量 × 1.10 | +1 |
| R3 | 5/10 线上方走强 | 现价 > MA5 > MA10 且 日内涨 ≥ 0.8% | +1 |
| R4 | 异常放量上行 | 换手 ≥ 20 日均量 × 1.8 且 日内涨 > 0 | +1 |
| R5 | 刷新 20 日高点 | 现价 ≥ 20 日最高价 | +1 |

> 注：R1（突破 20 日高点 0.2% + 放量）为死规则，已移除。

**卖出规则（sell_score）**：

| # | 规则 | 条件 | +分 |
|---|---|---|---|
| S1 | 跌破 10 日低点 + 放量 | 现价 < 10 日低 × 0.998 且 换手 ≥ 5 日均量 × 1.20 | +1 |
| S2 | 跌破 5 日线 + 跌幅扩大 | 现价 < MA5 且 日内跌 ≤ -1.5% | +1 |
| S3 | 回撤超 3% | 日内跌 ≤ -3.0% | +1 |
| S4 | 异常放量下行 | 换手 ≥ 20 日均量 × 1.8 且 日内跌 < -1.0% | +1 |

### 4.3 第二层：11 维评分（来源：a-stock-1to2）

| # | 维度 | 满分 | 最优区间 | 评分说明 |
|---|---|---|---|---|
| 1 | 流通市值 | 15 | 20-40 亿 | 太小无流动性，太大拉不动 |
| 2 | 换手率 | 15 | 主板 2.5-6% / 创业板 8-15% | 太低无资金关注，太高有出货嫌疑 |
| 3 | 量比 | 12 | 1.5-3x | 量比不足 = 量能不够；过高 = 警惕出货 |
| 4 | 封板质量 | 12 | 振幅 < 2.5% 强封 | 一字板（振幅 < 1% 且量比 < 0.5）→ **-20 分** |
| 5 | 股价 | 8 | < 8 元 | 低价股散户参与度高 |
| 6 | 板块强度 | **18** | 依题材动态赋值 | 最高权重，反映板块热度 |
| 7 | 龙虎榜 | 15 | 机构净买 + 游资 + 同营业部 | 多维度加分 |
| 8 | DDE 大单 | 8 | > 2.5 极强 | 主力参与度量化 |
| 9 | 板块类型 | 5 | 主板 10cm 额外 + 5 | 主板连板概率更高 |
| 10 | PE | 4 | < 25 最优 | 压低估值风险 |
| 11 | 一字板罚分 | **-20** | 振幅 < 1% 且量比 < 0.5 | 一字板无换手，A 杀风险高 |

### 4.4 第三层：战法匹配（来源：youzi）

| 战法 | 匹配条件 | 系数 |
|---|---|---|
| **龙头主升** | ① 新题材龙头已启动 ② 市场情绪积极 ③ 跟踪等待后主升买入 ④ 筑顶卖出纪律 | 满足 3/4 → 0.8 · 全满足 → 1.0 |
| **打板** | ① 题材够热 ② 量价齐升 ③ 龙头地位 ④ 市场焦点 | 满足 3/4 → 0.8 · 全满足 → 1.0 |
| **超跌反弹** | ① 缩量止跌 ② 放量杀跌 ③ 放量小阳止跌 | —（仅弱市启用，匹配即 0.6） |

> 若两种战法同时全满足，战法匹配系数取 1.0（不叠加）。

### 4.5 评分输出

| 综合评分 | 等级 | 含义 |
|---|---|---|
| **≥ 60** | **强烈候选** ⭐⭐⭐ | 三系统共振，可直接进入 L4 执行 |
| **45-59** | 一般候选 ⭐⭐ | 两系统共振，需人工二次确认 |
| **< 45** | 不输出 | 仅单一系统信号，可靠性不足 |

### 4.6 门控条件（继承 L2）

- L2 = 退潮期 → 全局清空所有候选
- L2 = 分歧/分化期 → 综合评分阈值提高至 60
- L2 = 降低权重（来自 L1）→ 综合评分阈值提高至 55
- 冷却机制：同一股票同方向 20 分钟内不重复输出

## 五、第四步 · L4 执行风控

### 5.1 仓位：取最严格限制

```
单票仓位 = min( L1 环境仓位上限, 20% )
```

| L1 环境 | 环境仓位上限 | 单票限制 | 实际仓位 |
|---|---|---|---|
| 正常模式 | 60-80% | ≤ 20% | **≤ 20%** |
| 降低权重 | 30-50% | ≤ 20% | **≤ 20%** |
| 全局屏蔽 | 0-20% | — | **0%**（不做） |

### 5.2 止损：三重触发

以下任意一条触发即执行止损，取最先触发的：

| 触发来源 | 规则 | 动作 |
|---|---|---|
| youzi | 亏损单不过夜 | 次日开盘即走 |
| 1to2 | 亏损 ≥ 3% | 无条件止损 |
| ashare-sop | sell_score ≥ 2 | 风控观察 → 人工评估后决定 |
| youzi + 1to2 | 次日不涨停 | 离场（打板策略核心逻辑） |

### 5.3 熔断与冷却

| 级别 | 触发条件 | 动作 |
|---|---|---|
| **分钟级** | 同股同向 20 分钟内 | 不重复报警 |
| **日级** | 连续 2 次失败 | 暂停交易 1 天 |
| **环境级** | L1 判全局屏蔽 / 大盘跌 > 2% | 暂停所有新开仓 |

### 5.4 每日复盘

```
收盘后必做（5 分钟）：
1. 当日信号回收 — 哪些触发、哪些执行、哪些错过
2. 样本录入 — 记录 buy_score + 11 维 + 战法匹配 + 实际结果
3. 周度汇总 — 胜率 / 盈亏比 / 错误分类
4. 因子追踪 — 哪些信号维度持续有效，哪些衰减
```

## 六、每日操作 SOP

### 08:30 · 盘前准备

```
Step 1: 运行 L1 融合判定
  → 获取上证/深证/创业板 MA20/MA60（tdx-connector K线）
  → 获取昨日赚钱效应数据（涨停数/炸板率/热点持续度）
  → 双系统交叉验证 → 输出环境状态 + 仓位上限
  → 若全局屏蔽 → 输出"今日不做"，流程结束

Step 2: 预处理 L2 候选池
  → 扫描昨日板块数据，预判今日可能主线
  → 标记已连续满足识别规则 2 天的板块
```

### 09:30-15:00 · 盘中扫描

```
每分钟循环：
  Step 3: L2 题材扫描
    → 涨幅 > 3% + 涨停 ≥ 3 + 连板 → 入池
    → 更新四阶段生命周期 + 健康度指标

  Step 4: L3 个股评分
    → 对 L2 主线池内的每只股票运行三层评分
    → buy_score ≥ 2 且 ≥ sell_score + 1 → 初筛通过
    → 叠加 11 维 + 战法 → 综合评分
    → ≥ 60 → 推送强烈候选
    → 45-59 → 推送一般候选

每 15 分钟：
  Step 5: 候选汇总推送
    → 输出排名前 5 的候选 + 每只评分明细
    → 标注冷却状态
```

### 15:00-16:00 · 收盘复盘

```
Step 6: L4 复盘
  → 当日信号回收 — 汇总所有触发的候选
  → 实际执行记录 — 买了哪些、为什么、结果
  → 样本录入 — 纳入周度复盘数据库
  → 因素追踪 — L3 buy_score 成分表现分析
```

## 七、常见问题

### Q1：两套环境系统分歧时为什么不听 ashare-sop 的？

ashare-sop 的 L1 基于中长期均线（MA20/MA60），对市场转变的反应有滞后性。youzi 的判断基于微观赚钱效应（涨跌比、涨停数、龙头表现），对情绪转折更敏感。在一个由情绪驱动的短线市场里，微观信号优先。

### Q2：为什么 buy_score 权重只有 30%，而 11 维权重 40%？

buy_score 只覆盖技术面（量价+均线），4 条有效规则。11 维评分覆盖基本面（PE）、资金面（DDE/龙虎榜）、筹码面（市值/换手/封板质量）、题材面（板块强度），维度更全面。战法匹配（30%）确保技术信号有心法逻辑支撑。

### Q3：如果三个系统的推荐完全不一致怎么办？

不输出。综合评分 < 45 的标的即使某一系统非常看好，也不进入候选。三个系统互相纠错：ashare-sop 可能漏掉的 → 1to2 捕获；1to2 可能误推的 → youzi 过滤；youzi 的主观偏差 → ashare-sop 校准。

### Q4：退潮期完全不能操作吗？

可以操作，但不通过本系统。退潮期全局屏蔽的是"主动性买入信号"。如果你有自己的对冲/套利策略，可以手动执行。方法论的态度是：不在退潮期推荐任何多头方向的操作。

---

> **核心理念总结**：先判断能不能做（L1 双闸门），再判断做什么（L2 三验证），再判断买哪只（L3 三层加权），最后决定怎么买/怎么卖（L4 统一风控）。每一步都有唯一的判定标准，每一条推荐都可追溯评分来源。
>
> ⚠️ 本方法论仅供研究学习，不构成投资建议。短期交易存在日亏 10-20% 的风险。人工终裁不可跳过。
