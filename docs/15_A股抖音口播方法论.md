## 一、五套底层分析框架

### 框架 1｜流动性-成交额档位风格模型
- ≈2.5万亿：流动性极充裕 → 大市值科技，易走科技牛
- ≈1.8万亿：中等存量 → 指数震荡，小盘题材占优（小票行情）
- <1.5万亿：流动性收缩 → 进攻退潮，转红利高股息防守

### 框架 2｜通胀-PPI/CPI 剪刀差行业分化
- ✅ 优先：上游资源品（金属/煤炭/化工，吃海外通胀）、AI硬件海外供应链、国产替代硬科技
- ⚠️ 谨慎：中游制造、家居家电、食品饮料、内卷赛道（光伏）、地产链消费（增收不增利）
- 宏观约束：海外加息/美债限制国内货币空间；外围走熊则 A 股难独行

### 框架 3｜冲锋号实战选股信号
- 技术形态：5日线拐头向上 + 连续2–3根小阳线缓抬
- 风控：回避连续大阳线暴涨的高位标的，禁止追高

### 框架 4｜跨境支付板块知识库
- 按市值梯队梳理辨识度个股，分析筹码结构/获利比例/资金流入
- 恒宝股份：板块辨识度标的，但筹码震荡属性强，每次须结合当下资金流向判断，不可无脑优先

### 框架 5｜一日交易五步法
1. 盘前做计划、预选观察池、想好止损止盈
2. 盘中严格执行，不临时冲动开仓
3. 持仓阶段持续风控
4. 到达条件果断止盈止损
5. 收盘后复盘，总结得失

## 二、三套口播模板

### 模板① 盘前（早盘策略）
钩子（反问式）→ 流动性预判（档位模型）→ 通胀剪刀差筛赛道/避雷 → 冲锋号选股思路 → 仓位提醒 + 风险提示

### 模板② 午间（盘中复盘）
点评上午盘面 → 实时成交额对照档位 → 识别主线/一日游 → 下午思路 + 仓位 → 冲锋号提示勿追高 → 风险提示

### 模板③ 盘后（收盘复盘）
钩子（别被单日涨跌带节奏）→ 全天成交额定风格 → 通胀分化析板块强弱 → 后续跟踪方向 + 外围风险 → 仓位 → 强制风险提示

## 三、写作纪律（硬性约束）

1. 前3秒设钩子，优先反问开头，留住停留
2. 口语化，适合真人出镜朗读，少长书面句
3. 每条末尾强制风险提示：「以上仅盘面复盘分析，不构成任何投资建议」
4. 多框架交叉验证：先流动性档位 → 宏观通胀分化 → 技术选股信号
5. 纳入外围市场/美债/海外货币政策，提示系统性风险

## 四、落地示例（2026-09-21 盘后）

用模板③落地：钩子「别急着下结论」→ 成交约2.03万亿（档位模型定风格）→ 医药/地产/业绩高低切换 → 跟踪医药高度与半导体回踩 → 仓位 + 免责。
