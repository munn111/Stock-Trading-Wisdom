## 三、HTML 翻页演示模板

适用于方法论/产品介绍类（非数据表格类）的翻页 HTML。9 页结构模板，CSS 变量集中管理。

### 配色系统
```css
--bg:#070b16;         /* 深空蓝底 */
--card:#111a2e;       /* 卡片底色 */
--red:#ff5a5f;        /* 涨红 */
--green:#1ed760;      /* 跌绿 */
--accent:#00d4ff;     /* 强调蓝青 */
--text:#e0e6f0;       /* 主文字 */
--muted:#8a96b0;      /* 次要文字 */
```

### 翻页壳子（9页，键盘和触摸翻页）
```html
<div class="deck" id="deck">
  <section class="slide">...</section>  <!-- 每页一个 section -->
</div>
<div class="nav" id="nav"></div>
```

导航 JS 自动根据 slide 数量生成按键，← → 空格键翻页，触摸滑动支持。

### 常用页面布局

**封面页**：kicker + h1 + lead 文字区域  
**卡片网格**：`.grid.g3` / `.g4` 三列/四列  
**表格页**：原生 `<table>` + 主题标签 `<span class="tag">`  
**流程图**：`.flow` 弹性盒子 + `.step` 步骤块 + `.arrow` 箭头  
**引用块**：`.quote` 左边框强调

### 响应式
```css
@media(max-width:780px){
  .g2,.g3,.g4{grid-template-columns:1fr}
  h1{font-size:42px}h2{font-size:32px}
}
```

### 卡片网格计算

```python
gx, gy = Inches(0.9), Inches(2.0)   # 起点
cw, ch = Inches(3.78), Inches(1.6)   # 每格宽高
gpx, gpy = Inches(0.18), Inches(0.18)# 间距

for i, data in enumerate(items):
```

### 常见陷阱速查

| 陷阱 | 解决方案 |
|---|---|
| 列宽非整数报 `TypeError` | `Inches(int(w))` 而不是 `Inches(w)` |
| `slide_layouts[6]` 不存在背景 | 第一个 shape 画满屏纯色矩形 |
| 中文引号在 f-string 报语法错误 | 用 Unicode 转义 `\u201c` 或独立字符串 |
| 表格单元格内容溢出 | 调大 `rh` (行高)，调小字体 |
| 卡片过多超出页面 | 增加每列行数或减小间距 `gpx/gpy` |

## 五、完整工作流 SOP

### Step 1：确定内容结构（~1分钟）
在脑子里把内容分成 6-12 页，每页一个主题。典型结构：
1. 封面 2. 概述/核心理念 3-7. 分章节 8. 总结/数据 9. 收尾

### Step 2：写 MD（~2分钟）
Markdown 作为单一真相源，确保所有数据、结论、表格准确。三件套中其他两个文件从 MD 派生。

### Step 3：生成 HTML（~3分钟）
- 复制翻页模板壳子（CSS + JS）
- 每页一个 `<section class="slide">`
- 用卡片网格 `.grid.g3` / `.g4` 展示要点
- 表格用原生 `<table>` + `.tag` 标签
- 配色保证：涨红 `#ff5a5f` / 跌绿 `#1ed760`

### Step 4：生成 PPTX（~3分钟）
- 复制 `scripts/build_pptx_template.py` 为 `build_{报告名}.py`
- 逐页替换内容数据（标题、卡片、表格数据）
- 运行脚本生成 `.pptx`
- 确认 `slides: N` 输出正确

### Step 5：验证（~1分钟）
三文件命名一致、内容同源、配色符合规范、页尾有免责声明。
