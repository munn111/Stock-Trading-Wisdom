## 一、westock-data (builtin skill) 踩坑

### 1. quote 接口返回 [SKILL_004] 未找到数据
- **现象**：对五大指数代码调用 quote 返回 `[SKILL_004] 未找到匹配数据`
- **触发场景**：午盘窗口(11:30左右)数据暂不可用；某些指数代码格式错误
- **解决**：改用 tdx-connector MCP `tdx_quotes` 拉取
- **日期**：2026-07-29

### 2. quote 代码前缀规则
- **必须**：沪市加 `sh` 前缀，深市加 `sz` 前缀
- **不**：纯数字代码会报错
- **正确示例**：`sh000001`(上证), `sz300308`(中际旭创), `sh688981`(中芯国际)
- **日期**：2026-07-09

### 3. quote 一次性上限
- **限制**：单次调用约15只股票
- **批量策略**：分批调用，每批15只，合并结果
- **日期**：2026-07-09

### 4. sector ranking 内部字段类型
- **陷阱**：`mainNetInflow` / `mainNetInflow5d` 是**字符串**不是数字
- **后果**：直接用于计算会报 `TypeError`
- **解决**：使用前 `float()` 转换
- **日期**：2026-07-10

### 5. sector ranking 只给涨榜
- **现象**：sector ranking 只返回涨幅靠前的板块
- **缺憾**：无法直接获取跌幅最大的板块
- **解决**：手动用 `quote` 逐个查询弱势板块 SW1 行业代码
- **日期**：2026-07-21

### 6. westock-data 命令入口
- **路径**：`C:\Users\Administrator\AppData\Local\Programs\WorkBuddy\resources\app.asar.unpacked\resources\builtin-skills\westock-data\scripts\index.js`
- **运行方式**：`node.exe scripts/index.js` (用托管 node 22.22.2)
- **注意**：需用绝对路径

### 7. 连接器命令
- `connect --exchange sh/sz` 实为陆股通标的清单，**不是**涨跌分布
- `lhb`(龙虎榜) 午盘无数据，只有盘后才有
- `hot stock/board` 的 `zdf` 涨跌幅是字符串

## 二、tdx-connector MCP 踩坑

### 1. tdx_quotes 不支持数组批量
- **现象**：`tdx_quotes` 只接受单只 `code` + `setcode`
- **错误做法**：传 `codes` 数组
- **正确做法**：单只并行多次调用，每只指定 `setcode`
- **日期**：2026-07-13

### 2. setcode 规则
| setcode | 交易所 | 代码范围 |
|---|---|---|
| `"1"` | 上海 | 6xxxxx, 68xxxx |
| `"0"` | 深圳 | 00xxxx, 30xxxx |
| `"2"` | 北交所 | 8xxxxx, 9xxxxx |

### 3. tdx_quotes 字段含义
- `Close` = 昨收 (不是今日收盘)
- `Now` = 实时价
- `pct` = 以 Now 计算
- `hasCwInfo="1"` 时返回 PE/PB/总市值/流通市值

### 4. tdx_lookup_stock 参数名
- **正确**：`query` (不是 `message` 或 `code`)

### 5. wenda_news_query 参数名
- **正确**：`query` (不是 `message`)
- **示例**：`wenda_news_query(name="半导体", bdate="2026-07-29", edate="2026-07-29", query="涨停")`

### 6. tdx_screener 查涨停
- 支持查"涨停/连板/涨幅大于9%/10天内以涨停收盘"等条件
- 返回：封单金额、封成比、板型、涨停原因
- `message` 参数(非 `query`)支持历史板信号

## 三、python-pptx 踩坑

### 1. 表格列宽浮点数报错
- **现象**：`TypeError: value must be an integral type`
- **原因**：`table.columns[i].width = Inches(2.5)` 中 2.5 在内部变成了浮点
- **解决**：始终用 `Inches(int(w))` 或直接用整数 EMU

### 2. 中文引号 → 语法错误
- **现象**：Python 字符串中的中文引号 `""` 被当作语法元素
- **解决**：用 Unicode 转义 `\u201c` / `\u201d`，或用单引号替代

### 3. 字符编码损坏
- **现象**：`墨`(U+58A8) 在特定编码下损坏为 `寿`(U+58FD)
- **解决**：用字节替换修复，或避免在 docstring 中使用 Windows 路径

### 4. 多行文本函数参数
- `add_multiline` 接受 3元组 `(text, size, color)` 或 4元组 `(text, size, color, bold)`
- 第四元 bold 默认 False

### 5. 生成速度
- 含大量表格的 PPT >30s，考虑用图表替代重复数据

## 四、其他工具问题

### 1. WebFetch 小红书登录墙
- 小红书原生内容需要登录，WebFetch 可能返回"页面不见了"
- 解决：用雪球/知乎/百度百家号等公开社媒替代，标注来源透明

### 2. 搜狗微信搜索限制
- 搜狗微信搜索反爬强，URL 是中间跳转链接
- 脚本已处理：生成可点击跳转的原文链接

### 3. 自动化任务延迟
- 定时任务可能延迟执行（如 12:00 实际 23:55）
- 重要分析不要完全依赖自动化，手动确认

## 五、快速排查清单

遇到问题时按以下顺序检查：

1. **代码前缀** → sh/sz 加了吗？
2. **参数名** → 是 `query` 还是 `message`？
3. **返回值结构** → 嵌套在 `data[].data` 下了吗？
4. **数据类型** → 字符串转 float 了吗？
5. **setcode** → 沪1深0北2 对了吗？
6. **EMU整数** → Inches 参数是整数吗？
7. **午盘窗口** → 11:30-13:00 数据可能不可用？
