# 16 · 报告输出规范：副文本格式 + 涨停池排版范式

> 沉淀时间：2026-09-03（副文本/涨停池排版）+ 2026-09-04（两条铁律/数据来源升级）
> 定位：涨停复盘与盘面汇报类报告的**输出规范**，与 `docs/08_报告输出三件套规范.md`（三件套铁律）配套，补齐「副文本精炼版」与「涨停池专页」两层排版标准。

---

## 一、副文本优先铁律

盘后/盘中汇报**先出「副文本精炼版」**，再出长报告（MD/HTML/PPT）做详情支撑。

副文本结构（固定顺序）：
1. **一句话判断定调**
2. **三条主线**（emoji + 定位标签）
3. 个股反引号 + 关键数字加粗
4. ⚠️ 风险区（emoji 事件）
5. 结尾来源 + 免责

**格式规则**：
- 个股用反引号 `` `代码` ``
- 关键数字 `**加粗**`
- 涨跌 +红 / -绿
- 主线编号 ❶ ❷ ❸
- 定位标签语义要准：**底仓**=避险防守 / **进攻**=题材博弈 / **按兵不动**=等待信号
- 动作提示嵌主线行尾（"看龙头是否连板""等今晚美股表态再动手"），给方向不给死结论

**结尾固定**：`（数据：@来源 + 来源；仅供参考，不构成投资建议）`

---

## 二、涨停池专页排版范式

涨停复盘类报告**必须**包含「涨停池」专页（按 pretty-skills「A股研报流水线」第10页范式）。

**顶部三件套**：
- 左竖线（5px #FF5A5F / #F5B94B 渐变）
- 大字「涨停池」
- 右上日期徽章（圆角胶囊 + 金边 #F5B94B）

**副标题**：`共 N 家 · 第 X / Y 页`

**五列表格**：

| 列 | 样式 |
|---|---|
| 股票 | 名称加粗主白 + 代码次灰 |
| 连板 | 颜色梯度：5板/4板红 #FF5A5F/#FF8C66，2板橙 #F5B94B，1板白 |
| 首封 | HH:MM 浅灰 |
| 封单 | 涨红 + 亿/万 |
| 题材/原因 | 标签串用 `+` 蓝色拼接 |

**底部双声明**：
- 左 = 数据口径（"盘面口径·仅研究参考·不构成投资建议"）
- 右 = 来源水印（小红书号 / 公众号 / 数据源）

---

## 三、两条铁律（2026-09-04 升级）

**① 完整全量**：所有涨停股全列不截断，禁止"强信号 TOP N + 其余只列名"两段式；首封/封单属 Level-2 行情，拿不到就标「—」如实注明。

**② 板块 + 强度排序**：先按板块分组（题材归因 → 归一为 9 大主线板块），板块间按最高连板降序（同级按家数降序），板块内按连板数降序。

---

## 四、涨停数据来源（2026-09-04 更新）

| 数据 | 来源 | 要点 |
|---|---|---|
| 题材归因 | 同花顺 `getharden` 接口 | `zx.10jqka.com.cn/event/api/getharden/date/YYYY-MM-DD`，零鉴权，返回涨停股 + `reason` 题材归因 |
| 连板数 | 腾讯日K线自算 | `web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={sh\|sz}{code},day,,,25,qfq` 前复权，连续涨停天数=连板数；须过滤目标日之后的盘中数据、创业/科创 20% 阈值、主板 10% |
| 首封/封单 | Level-2 行情 | 公开接口不可得，标「—」 |

**落地文件**：`今日涨停池_YYYY-MM-DD.html` + `.pptx`（6 页：封面 / 连板梯队 / 板块总览 / 完整明细上 / 完整明细下 / 主线研判）

## 五、大盘盘面分析四招（2026-09-03，公众号盘前解读方法论）

大盘/盘面分析请求时，须结合公众号盘前解读方法论，不能只拉数据堆结论。

1. **7 板块结构**：盘前热点 / 涨跌停·量能 / 连板·监管 / 公告 / 新高·新低 / 全球市场 / 人气热榜
2. **事件 → 个股法**：由事件催化落到具体标的
3. **XTYB 连板标注**：连板梯队统一标注
4. **批判性使用法**：硬信息照单收 / 主观点评自己下 / 涨停题材归类 ≠ 板块趋势
