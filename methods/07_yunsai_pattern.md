### 关键特征
- **首板**：有明确题材(算力/智算中心) + 板块共振(浪潮信息中报预增引爆)
- **洗盘5-8日**：不破首板实体中点 + 不破10日线
- **缩量信号**：洗盘末量能萎缩至首板量的1/2以下
- **二板形态**：早盘快速秒板 + 缩量(抛压已尽) + 大封单

## 二、形态筛选标准

### 初筛 (tdx_screener)
```
条件：
- 10天内出现以涨停收盘 (非今日)
- 今日缩量 (成交量 < 5日均量)
- 多头排列 (5日线 > 10日线 > 20日线)
- 非ST
- 今日未涨停 (chg < 9.5%)
```

### K线复核 (tdx_kline 30根日线)
逐只检查：
1. 首板日期：精确到哪天涨停
2. 洗盘天数：首板到今日间隔
3. 量能变化：是否缩量至首板量的1/2以下
4. 均线支撑：是否守住10日线
5. 平台形态：是否形成缩量横盘平台

### 加分项
- 首板封单强硬(买一封单>流通盘0.5%)
- 题材属于主线(非一日游题材)
- 有后续催化(公告/政策/事件)未兑现
- 板块内同形态的票形成集群

## 五、操作框架

### 买点
| 买点 | 条件 | 仓位 |
|---|---|---|
| 突破买点 | 放量突破平台/前高 + 板块共振 | 首笔1/3 |
| 回踩买点 | 缩量回踩10日线 + 分时承接确认 | 首笔1/3 |
| 确认加仓 | 次日放量确认突破 + 封板 | 加1/3 |

### 止损
- 跌破10日线 → 减半仓
- 跌破首板实体中点 → 全清
- 炸板且不回封 → 次日冲高即出

## 六、风险提示
- 此形态非100%胜率：洗盘可能演变为真出货
- 题材一日游风险：确认首板逻辑仍有后续催化
- 缩量可能是无人接盘而非浮筹出清：需结合板块热度判断
- 高PE/科创板须额外谨慎(如铂力特PE483)
