## 一、趋势选股类

### 1. 均线多头筛选法（最基础）

**逻辑**：均线多头排列 = 上升趋势确立，顺势而为不做反转。

| 条件 | 具体标准 |
|---|---|
| 均线排列 | 5日 > 10日 > 20日 > 60日，向上发散 |
| 股价位置 | 站稳5日线，回调不碰20日线 |
| 均线斜率 | 5日/10日均线斜率 > 30度 |
| 量价 | 上涨放量（≥5日均量1.5倍），回调缩量 |
| RPS | 20日RPS ≥ 80（近20日强于80%个股） |

**买入**：放量突破前高当日尾盘 / 缩量回踩5日线企稳  
**止损**：收盘跌破20日均线  
**适用**：所有行情，但熊市需配合基本面筛选  

### 2. 三维共振选股法（均线+量能+MACD）

| 维度 | 条件 |
|---|---|
| 均线 | 5/10/20日均线多头排列，股价站5日线 |
| 成交量 | 突破放量(≥5日均量1.5倍)，回调缩量至峰值1/3以下 |
| MACD | 零轴上方金叉，红柱持续放大，无顶背离 |

**三点缺一不可**。同时满足时入场，任一条件破坏时减仓/离场。

### 3. RPS动量选股法

**逻辑**：欧奈尔CANSLIM体系核心，RPS(20)≥80筛选市场最强20%个股。

**筛选条件**：
- RPS(20) ≥ 80，RPS(60) ≥ 70
- 股价创20日新高
- 近5日至少2日放量(>5日均量)
- 流通市值 50-500亿

**买点**：杯柄突破/平台突破日  
**止损**：跌破突破日最低价

## 二、形态选股类

### 4. 回踩5日线缩倍量（模式B）★ 实战验证

**前提**：近期出现过涨停或巨量阳线（涨幅>7%，量能>5日均量2倍）

| 阶段 | 特征 | 操作 |
|---|---|---|
| 回踩日 | 缩量至前一天50%以下，不破10日线 | 尾盘确认，20%仓位试错 |
| 确认日 | 次日阳线反包 | 加仓30% |
| 拉升日 | 突破前高 | 持有/止盈，50%仓位 |

**止损**：跌破10日线（回踩日）、跌破5日线（确认日）  
**实战案例**：利仁科技、兆新股份（均已验证）

### 5. 龙回头战法（最稳低吸）

**逻辑**：主升浪后缩量回调5-8天→首次放量阳线反包→重启主升。

| 条件 | 标准 |
|---|---|
| 前提 | 之前经历明显主升浪（涨幅>30%） |
| 回调天数 | 5-8天 |
| 量能 | 回调缩量，不破20日线/前平台 |
| 指标 | MACD不背离，KDJ低位金叉 |
| 进场信号 | 首次放量阳线反包 |

**止损**：跌破20日线或前平台低点  
**胜率**：震荡市70%+，熊市禁用

### 6. 云赛同款形态 ★ 已沉淀

**逻辑**：首板→中继洗盘→缩量二板接力。

| 步骤 | 特征 |
|---|---|
| 1 首板 | 涨停板，收盘在前日涨幅+10% |
| 2 洗盘 | 回踩至20日均线附近，不破，缩量 |
| 3 二板 | 再次出现涨停，缩量（比首板缩量30%+） |

**买点**：二板当日打板或次日低吸  
**止损**：跌破首板最低价

### 7. 分歧转一致（短线打板进阶）

**形态**：连板后炸板放量(1.5-2倍)→次日高开高走反包。

| 条件 | 标准 |
|---|---|
| 前提 | 前日涨停后炸板，量能1.5-2倍 |
| 次日 | 高开，早盘高走，量能不减 |
| 板块 | 龙头抗跌，板块回流 |

**买点**：反包确认时小仓参与  
**止损**：次日低开低走立即止损

### 8. N型战法（阳包阴）

**形态**：上涨途中出现阴线回调→次日大阳线反包整根阴线。

**买点**：反包阳线收盘确认  
**止损**：反包阳线最低价

## 三、题材/事件驱动类

### 9. 事件驱动五步法 ★ 已沉淀

```
事件发生 → 影响哪类供需/政策/订单 → 对哪个产业链环节最直接 → 哪些公司主营强相关 → 股价位置是否允许参与
```

| 类型 | 例子 | 交易含义 |
|---|---|---|
| 政策催化 | 产业政策、国常会 | 找板块主线 |
| 产业事件 | 发布会、订单、涨价 | 找产业链环节和弹性标的 |
| 公司公告 | 合同、投资、并购 | 只影响个股或少数同类 |
| 海外映射 | 特斯拉、英伟达 | 确认A股主营相关性 |
| 灾害/突发 | 矿难、停产事故 | 供给收缩和替代需求 |

### 10. 板块梯队分析法 ★ 已沉淀

| 梯队 | 定义 | 操作 |
|---|---|---|
| T0 情绪龙头 | 板块内最高板/最先涨停，小市值高弹性 | 打板或排队 |
| T1 核心中军 | 趋势龙头，大市值机构持仓，沿5日线推升 | 低吸5日线 |
| T2 强势跟涨 | 跟风涨停或大涨5-8%，量能放大 | 日内套利 |
| T3 补涨龙 | 龙头滞涨后低位启动，首板或2板 | 挖掘低位 |
| 风险池 | 蹭概念、弱关联、高位放量滞涨 | 回避 |

### 11. 产业链拆解法

不要只写"利好某板块"，必须拆到环节：
- **上游**：原料、设备、材料、资源
- **中游**：制造、封测、系统集成、核心零部件
- **下游**：应用、渠道、内容、终端品牌
- **配套**：物流、检测、营销、云服务

### 12. 涨价线选股法 ★ 7月实战验证

**识别涨价信号 → 确定涨价幅度和持续性 → 找最纯正受益标的**

| 涨价方向 | 幅度 | 受益标的 |
|---|---|---|
| MLCC（三星+30%） | 大幅 | 三环集团/风华高科/洁美科技 |
| 磷酸铁锂（+2000元/吨） | 温和 | 湖南裕能/德方纳米 |
| 六氟化钨（+30~40%） | 大幅 | 中船特气/雅克科技 |
| 碳酸锂（近一年翻倍） | 极端 | 赣锋锂业/天齐锂业 |

**筛选条件**：涨价幅度>10% + 持续性>1个月 + 标的营收占比>30%

## 四、基本面选股类

### 13. 六维选股体系 ★ 已沉淀

| 维度 | 标准 | 权重 |
|---|---|---|
| 政策赛道 | 国家重点支持行业（半导体/新能源/AI/机器人） | 20% |
| ROE | ≥15% | 20% |
| PEG | ≤1.2 | 15% |
| 技术共振 | MACD金叉+均线多头+RSI 50-80 | 20% |
| 安全边际 | PE分位<70%或PB<行业中位数 | 15% |
| 资金面 | 北向连续增持+机构持仓>5%+换手活跃 | 10% |

**仓位法则（3331）**：
- 30% 核心仓位（六维高评分）
- 30% 卫星仓位（题材弹性）
- 30% 防御仓位（高股息/黄金）
- 10% 现金

### 14. 卡脖子理论六步选股 ★ 已沉淀

| 步骤 | 内容 |
|---|---|
| 1 识别瓶颈 | 中国在哪些技术/材料上被"卡脖子" |
| 2 替代紧迫度 | 国产替代的紧迫程度和时间窗口 |
| 3 国产化率 | 当前国产化率<30%才有空间 |
| 4 龙头壁垒 | 技术壁垒高、竞争对手少 |
| 5 订单兑现 | 已有实质订单，不是纯概念 |
| 6 估值动量 | 估值相对合理，有机构背书 |

**已精选**：10赛道57只（半导体设备、材料、EDA、光刻胶、存储、先进封装等）

### 15. 获利比例选股法 ★ 7月实战验证

| 条件 | 标准 |
|---|---|
| 获利比例变化 | 从<50%跳升至>50% |
| 年涨停次数 | ≥6次（妖股基因） |
| 技术面 | MACD金叉 + 成交量放大 |
| 板块 | 属于当前热门主线 |

**高级版**：获利比例从<80%跳升至>80%，信号更强但数量更少。

### 16. PEG估值选股法

| 条件 | 标准 |
|---|---|
| PEG | ≤1.0（低估），≤1.5（合理） |
| 营收增速 | >15% |
| 行业 | 成长行业（科技/医药/新能源） |

## 五、资金面/情绪选股类

### 17. 龙头战法 ★ 核心

**五要素识别龙头**：辨识度 | 题材高度 | 封单硬度 | 换手率 | 板块地位

**四大打板形态**：

| 形态 | 时机 | 操作 |
|---|---|---|
| 首板打板 | 启动期，主线首次涨停 | 尾盘14:30确认封单，要题材新鲜+缩量+板块效应 |
| 低吸回封 | 冰点/分歧日，炸板回封 | 炸板回封瞬间，看封单二次转强 |
| 连板接力 | 高潮期，一进二/二进三 | 竞价高开5-7%或秒板，分歧转一致+量能配合 |
| 龙头首阴低吸 | 退潮初期，龙头首次调整 | 首阴不破关键均线低吸，只做真龙，断板即止损 |

**盘口五口诀**：①买一封单>流通盘0.5%且全天不撬 ②一字/T字最强/尾盘偷袭最弱 ③首板缩量金叉最佳 ④龙头封死带动中军=强 ⑤连板竞价高开5%+放量=一致预期

### 18. 连板天梯四维选股法 ★ v3.1

| 维度 | 内容 | 判断 |
|---|---|---|
| 主线分布 | 涨停数/占比/龙头 | >30%共识形成 |
| 时间戳 | 涨停时间到分钟 | 09:30-09:45最强 |
| 时间分级 | 早盘秒板→尾盘封板 | 尾盘封板率>30%警惕 |
| 梯队健康度 | 每条主线独立评估 | 梯队完整=板块强 |

### 19. 北向/主力资金选股法

| 条件 | 标准 |
|---|---|
| 北向资金 | 近5日连续净买入 |
| 主力资金 | 近3日主力净流入 |
| 融资余额 | 处于近一年50%分位以下（尚未过热） |
| 筹码 | 股东户数减少（筹码集中） |

## 六、特殊环境选股法

### 20. 暗线识别法 ★ v3.2 7月验证

**逻辑**：在主线高潮/崩溃的间隙，捕捉次线机会。

**识别要素**：
- 催化多重（国际合作+龙头回购+政策）
- 龙头明确（连板+板块效应）
- 时间窗口精准（主线空隙冒头）

**实战案例**：固态电池暗线（金龙羽/纳百川/中国宝安，7/30科技崩溃间隙）

### 21. 防御轮动选股法 ★ v3.2

**三日轮动法则**：
- Day1：银行+白酒双护盘 → 买大金融/白酒龙头
- Day2：小食品+教育扩散 → 切换至中小市值消费
- Day3：大市值消费确认主线 → 重仓确认方向

### 22. 结构化选股法 ★ 今日实战验证

**逻辑**：先用SOP判定情绪周期→确定主线板块→在主线板块内选龙头→用六维/卡脖子/获利比例三维验证→再用技术面找买点。

```
情绪周期判定(冰点/复苏/高潮/退潮)
    ↓
板块排行榜(涨幅+资金+概念)
    ↓
主线板块成分股 → 龙头识别(辨识度/封单/换手/板块地位)
    ↓
三维验证(六维+卡脖子+获利比例)
    ↓
技术买点(均线/量价/形态)
    ↓
仓位管理(3331法则+环境调整)
```
