# 六维选股体系

> 沉淀来源：2026-07-16 "买股技巧合集"(全网搜集) + 六维选股清单实战(10只精选)
> 定位：散户通用的、可量化的选股框架，区别于龙头战法的游资超短专版

---

## 一、六维框架

| 维度 | 指标 | 标准 |
|---|---|---|
| **1. 政策/赛道** | 是否属于国家战略方向 | 政策支持 + 行业高景气(增速>20%) |
| **2. 盈利能力** | 连续净利润增长 | 连续3年净利润正增长 + ROE≥15% |
| **3. 估值合理** | PEG指标 | PEG≤1.2，PE<行业均值 |
| **4. 技术面** | 趋势与支撑 | 多头排列 + 放量突破平台/缩量回踩支撑 |
| **5. 安全边际** | 非ST/非高危 | 排除ST、*ST、立案调查、大额减持 |
| **6. 资金面** | 主力/北向 | 主力净流入+北向持仓稳定(非一日游) |

---

## 二、筛选流程

### 第一轮：基本面初筛 (tdx_screener)
```
条件：ROE≥15% + 营收净利连续增长 + 非ST
结果：约20-30只进入候选池
```

### 第二轮：估值过滤 (tdx_quotes hasCwInfo=1)
```
剔除：PE>100(无业绩支撑) / 股价处于历史95%分位以上 / 近5日跌停
保留：PEG≤1.2 + 股价处于合理区间
```

### 第三轮：人工复核
```
检查：公告澄清/减持计划/质押率/行业景气度变化/题材真实性
排除：蹭概念(如名字带"智能"但主业无关) / 伪国产替代 / 一日游题材
```

---

## 三、仓位管理：3331法则

| 批次 | 时机 | 仓位 | 条件 |
|---|---|---|---|
| **第一批(3成)** | 回调至关键均线支撑 | 30% | 缩量企稳 + 分时承接 |
| **第二批(3成)** | 放量确认突破 | 30% | 收盘站稳关键位 + 量比>1.5 |
| **第三批(3成)** | 趋势加速 | 30% | 新高确认 + 板块共振 |
| **预留(1成)** | 随时保持现金 | 10% | 应对突发/换股机会 |

---

## 四、卖出与止损

| 信号 | 动作 | 理由 |
|---|---|---|
| 亏损-5% | 无条件止损 | 保命第一 |
| 亏损-10% | 绝对止损 | 短线不扛单 |
| 逻辑证伪 | 立即卖出 | 买入理由消失(业绩暴雷/重组失败) |
| 放量滞涨 | 减半仓 | 主力出货信号 |
| 移动止盈 | 回撤3%触发 | 保护利润 |
| 跌破20日线 | 中线清仓 | 趋势破坏 |

---

## 五、新手避坑七条

1. **不抄底**：下跌趋势中不接飞刀，等止跌信号(长下影+放量)
2. **不追高**：涨幅>7%且无板块效应不追，警惕尾盘偷袭
3. **警惕假突破**：突破前高但缩量/无板块共振 = 大概率假突破
4. **不加杠杆**：绝对不借钱炒股、不配资
5. **不ALL IN**：单票≤30%，总仓≤80%
6. **不听消息**：微信群/短视频"内幕"99%是出货信号
7. **不频繁交易**：月交易≤5次，提高每笔质量
