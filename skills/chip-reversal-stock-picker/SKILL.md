# chip-reversal-stock-picker · 短线冲高选股（筹码分歧回补）

把"短线选股 + 交易执行"的全流程标准化。解决「短线买什么、为什么、什么时候买、什么时候卖」。
决策底座与 `trading_methodology.md` 战法库互补——本 case 管"筹码分歧回补"这一种短线形态的完整打法。

单一真相源：`pretty-skills.local/金融投资/短线冲高选股/content.md`（3F Content 范式，7 页）。

## 一、核心形态：筹码分歧回补（6 条件，逐条核对）

| # | 条件 | 含义 |
|---|------|------|
| 1 | 前日获利比例 > 50% | 中期筹码偏强，排除纯弱势股 |
| 2 | 昨日获利比例 < 50% | 短线获利盘出逃，制造分歧洗浮筹 |
| 3 | 昨日量 < 5日最大量 × 50% | 卖盘枯竭，抛压释放完毕 |
| 4 | 今日获利比例 > 50% | 资金重新介入，筹码回补 |
| 5 | 今日放量 | 资金介入力度大，确认真实介入 |
| 6 | 涨幅 ≤ 7% | 吸筹为主，排除买不进的涨停 |

- 六条全中 = 高置信「缩量企稳 + 放量回补」形态，下日冲高概率最高。
- 缺任一条 → 降级或放弃，别只盯"放量"就下手。

## 二、选股执行三步

1. 金融工具筛选（主板 + 六条件）。
2. 排除涨停板标的（买不进无意义）。
3. 资金面+量价排序：**主力净流入最大 > 量比最大 > 换手率 5%-10% > 流通市值 > 50亿**。

## 三、四维度共振（分级结论）

- 板块景气度（政策/订单/价格 + 产业链位置 + 轮动节奏）
- 资金面（近5日主力净流入>0、超大单>0、量比>1.5、换手5-10%、主力增仓>5%）
- 基本面（营收>20%、净利>30%、毛利率行业以上、合同负债环比增、近1月有调研）
- 消息面（公告/业绩会/政策/研报上修）
- **四维齐 → 持续行情型；三维 → 短线冲高型；二维以下 → 不操作。**

## 四、冲高概率 + 交易执行

**竞价抢筹（3 情景）**：乐观=高开3-5%+竞价放量+主力流入→竞价分批买；中性=平开/小低开→观望等突破；悲观=低开2%+主力流出→不买。

**主力成本线（4 价位）**：主力成本线=核心支撑（站稳可买）；5日均线=趋势线（跌破减仓）；压力位=前高（放量突破加速）；目标位=成本线+突破后看前高。

**买卖纪律**：买入=竞价高开3-5%+竞价放量+站稳成本线+主力流入；卖出=放量滞涨(涨幅<1%)/跌破5日线/主力净流出>前日流入50%；止损=破成本线；止盈=压力位→前高。

## 五、数据源（westock-data，字段名务必记准）

- 筹码：`westock-data chip <code>` → `chipProfitRate`(获利比例) / `chipAvgCost`(筹码均价=主力成本线) / `chipConcentration90|70`(集中度)。
- 资金：`westock-data fund flow <code> --start --end` → `MainNetFlow`(主力) / `JumboNetFlow`(超大单) / `RetailInFlow|OutFlow`(散户)。
- 技术：`westock-data technical <code> --indicator all` → MA/MACD/KDJ/RSI/BOLL。
- 量价：`westock-data kline <code> --period day --limit N` → 量比、换手率(exchange 字段)。
- 基本面/消息面：WebSearch 公开研报/公告，≥2 源交叉。

## 六、关键判据（镜像结构，务必分清）

- **健康吸筹** = 主力净流入 + 散户净流出（如中天科技 9/11 主力 +7.85亿/散户流出）。
- **高位派发** = 主力净流出 + 散户净流入（9/4 大阴线前车之鉴：主力 -7.97亿/散户 +8.29亿）。
- 两者是镜像，尾盘竞价偷袭拉最高价 + 最后 3 分钟放量 = 疑似诱多，别当抢筹。
