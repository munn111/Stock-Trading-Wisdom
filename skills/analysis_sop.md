## 一、复盘流程 (每日收盘后)

### 1. 数据获取
```
Step 1: 五大指数行情
  → westock-data quote sh000001,sz399001,sz399006,sh000688,sh899050
  → 备用: tdx-connector tdx_quotes (单只多次调用)

Step 2: 板块涨跌榜
  → westock-data sector ranking (涨幅前20)
  → 跌幅板块: 手动 quote SW1 行业代码
  → 注意: mainNetInflow 是字符串，需 float()

Step 3: 涨跌分布
  → westock-data changedist

Step 4: 涨停/连板/封单
  → tdx-connector tdx_screener (涨停 + 连板 + 首板)

Step 5: 龙虎榜 (盘后才有)
  → westock-data lhb 或 tdx-connector

Step 6: 新闻/催化
  → tdx-connector wenda_news_query (参数名: query 非 message)
```

### 2. 分析框架
```
1. 市场画像: 量(成交额) + 价(指数) + 比(涨跌比) + 板(涨停跌停数)
2. 主线识别: 涨停最多的3个板块 + 各自事件催化 + 梯队完整性
3. 连板梯队: 高度龙 → 断层 → 健康
4. 情绪周期: 冰点/复苏/高潮/退潮 (对照 emotion_cycle.md 校准)
5. 风格轮动: 大小盘剪刀差 + 价值/成长 + 进攻/防御
```

### 3. 昨��预判验证
```
每天对比昨日判断 vs 今日实际:
- 看好的方向 → 实际涨跌? ✅/❌
- 提示的风险 → 是否应验? ✅/❌
- 记录偏差原因 (V反? 消息突袭? 情绪透支?)
- 调整今日判断置信度
```

## 二、选股流程 (多策略并行)

### A. 龙头战法 (游资超短)
```
1. 情绪周期判定 → 冰点?复苏?高潮?退潮?
2. 涨停 screener → 找最高辨识度龙头
3. 五要素过滤: 辨识度/题材/封单/换手/地位
4. 连板梯队结构 → 一进二?二进三?高度龙?
5. 买点形态匹配: 首板打板/低吸回封/连板接力/首阴低吸
6. 风控: 冰点总仓≤5成/单票≤1/5/-5%砍
```

### B. 六维选股 (散户通用)
```
1. tdx_screener: ROE≥15%+营收净利连续增长+非ST
2. tdx_quotes(hasCwInfo=1): 拉真实PE/ROE/PEG
3. 估值过滤: 剔除PE>100/PEG>1.2/高位/跌停
4. 技术面共振: 多头排列+放量突破或缩量回踩
5. 3331仓位: 3成回调低吸+3成突破加仓+3成趋势持有+1成现金
6. 止损: -5%砍/逻辑证伪立即清
```

### C. 卡脖子理论 (产业趋势)
```
1. 识别被卡环节 (BIS清单/瓦森纳/出口管制)
2. 评估替代紧迫度 (90-100=无替代/S级)
3. 测算国产化率空间 (当前→3年目标→增量)
4. 筛选龙头壁垒 (技术/客户/产能)
5. 核实订单兑现 (合同/中标/CAPEX)
6. 估值动量过滤 (PE<均值+PEG<1.2)
```

### D. 云赛同款形态 (首板→洗盘→二板)
```
1. tdx_screener: 10天内涨停+缩量+多头排列+非ST+今日未板
2. K线复核: 30根日线 → 验证首板/洗盘/缩量结构
3. 评分: 首板质量20+洗盘结构25+量能信号20+题材20+技术15
4. ★★★≥70 → 核心观察，买点=放量突破/缩量回踩
5. 止损: 跌破10日线→减半，跌破首板实体中点→全清
```

## 五、每日盘前七问 Checklist

1. 情绪周期在哪个阶段？(对照 emotion_cycle.md)
2. 最高辨识度龙头是谁？题材大小？
3. 连板梯队完整吗？断板率多少？
4. 目标股封单硬吗？换手健康吗？有板块效应吗？
5. 买点符合形态吗？
6. 止损位/仓位符合周期吗？
7. 有大级别消息未落地吗？要控仓吗？
