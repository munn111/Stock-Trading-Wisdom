## 一、周期四阶段 (7月实测数据校准)

### 冰点期 (恐慌)
| 指标 | v2.0旧标准 | v3.0新标准 (7月校准) |
|---|---|---|
| 涨停家数 | <20 | <40 (考虑市场扩容4000+只) |
| 连板高度 | <3板 | <3板 |
| 昨日涨停今日表现 | 大跌 | 断板率>60%、昨日连板仅<30%红 |
| 跌停家数 | - | >100或跌停>涨停 |
| 涨跌比 | - | <0.2 (涨<20%) |

**7月实例**：
- 7/13：32涨停/176跌停，断板率67%，冰点确认
- 7/24：37涨停/仅9%个股上涨，冰点

**策略**：空仓或极轻仓试错**新首板**活口，绝对不打昨日老龙。

### 复苏期 (修复)
| 指标 | v3.0标准 |
|---|---|
| 涨停 | 40-70家 |
| 连板高度 | 3-4板出现 |
| 亏钱效应 | 减少，封板率>70% |
| 上涨比例 | 50-75% |

**7月实例**：7/14 午后V反，87涨停/4211上涨76%，复苏确认

**策略**：加仓核心股，低吸首板/打主线首板。

### 高潮期 (主升)
| 指标 | v3.0标准 |
|---|---|
| 涨停 | >80家 |
| 连板高度 | >5板 |
| 赚钱效应 | 鸡犬升天，20cm频出 |
| 涨跌比 | >5:1 |

**7月实例**：
- 7/27：121涨停/5195上涨/涨跌比18.16，典型高潮
- ⚠️ 但7/28直接翻脸：创业-7.35%/通信-10.88%

**⚠️ 7月教训**：高潮次日可能直接崩盘，不要因一天高潮就放松警惕。

**策略**：持股待涨、去弱留强，但高潮日减仓到6成以下，不追补涨。

### 退潮期 (退烧)
| 指标 | v3.0标准 |
|---|---|
| 高标 | 断板，A杀 |
| 涨停 | 骤减 <50家 |
| 跌停 | >30家 |
| 主线板块 | 集体破位 |

**7月实例**：
- 7/28：创业板-7.35%，通信-10.88%(板块级崩盘)，银行独撑
- 7/22：沪强深弱极端分化(上证+0.07% vs 创业-3.23%)

**策略**：清仓空仓，管住手，等冰点信号再试错。

## 四、周五/周一效应 (7月验证)

- **周五**：资金博弈周末利好，但若周末消息落空 → 周一大跌
- **周一**：
  - 若周末利好：前排一字买不到，后排接力谨慎
  - 若周末利空：核按钮集中营，空仓最好
  - ⚠️ 7/27(周一)高潮 → 7/28(周二)崩盘 = "周末发酵→周一兑现→周二翻脸"模式

---

> **核心教训**：A股情绪可在24小时内从极端贪婪切换到极端恐惧。高潮日是减仓日，不是加仓日。盘后必须复核收盘，不固化盘中判断。
